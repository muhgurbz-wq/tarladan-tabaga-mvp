# Tarladan Tabağa — MVP

Üretici ile tüketici/işletmeleri doğrudan buluşturmayı, ürün kaynağını görünür kılmayı ve tedarik akışını dijitalleştirmeyi hedefleyen çalışan web MVP demosu.

## MVP'de çalışan akışlar

- Ürün pazaryeri ve kategori filtreleme
- Ürün bazlı demo talep oluşturma
- Lot koduyla ürün izlenebilirliği (`TT-2026-001`)
- Yatırımcı/operasyon demo paneli
- Mobil ve masaüstü uyumlu arayüz

## Demo verisi hakkında

Uygulamadaki üretici, stok, fiyat, oran ve operasyon rakamları yalnızca ürün deneyimini göstermek için kullanılan örnek verilerdir; doğrulanmış ticari performans veya gerçek satış verisi değildir.

## Çalıştırma

Herhangi bir kurulum gerekmez. `index.html` dosyasını tarayıcıda açın.

## Sonraki ürün aşamaları

4. Harita ve lojistik eşleştirme
5. QR/lot bazlı izlenebilirlik
6. Ödeme altyapısı ve yönetim paneli
